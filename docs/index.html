Epi-Duo · virtual cell · epigenome prior

扰动标签是 one-hot，基因本身对模型一无所知

STATE 一类虚拟细胞模型把「敲掉哪个基因」写成一个可学习的嵌入。 它看不到这个基因的启动子是否开放、有没有转录因子结合、有没有远距离接触。 Epi-Duo 把公开的 K562 表观数据做成两种先验，接到同一套集合到集合的骨架上： 模型 A 先做成候选调控网络，模型 B 把顺式元件直接编码。

同一张证据表，两种读法；同一套基准，同一套 cell-eval。
先验路径零初始化起步，所以训练开始时两个模型都等价于无先验骨架。

00 / 问题

标签知道「敲了谁」，但不知道这个基因是谁

虚拟细胞模型的标准接口是：输入对照细胞集合与扰动标签，输出扰动后的细胞集合。 扰动标签通常是基因名的 one-hot 或嵌入。对模型来说，敲 GABPA 和敲一个从未见过的基因， 差别只在「这个编号有没有被训练过」，而不在「这个基因的调控邻域长什么样」。

表观基因组给出了另一条路：启动子可达性、因子结合、Hi-C 环、甲基化——这些在公共数据库里已经有了。 问题变成：怎么把这些证据接进集合到集合的预测器，而且接进去之后真的有用。

02 / 同一张证据表

两种模型读的是同一批峰、环和甲基化

元件 = ENCODE K562 ATAC 峰（— 个）。 ChIP 结合只在 ATAC 峰内计数；启动子窗口是每个转录本 TSS 的 [−1000, +1001)； 环是四份 Hi-C loop 的并集（— 条）； 甲基化是两次 WGBS 的覆盖加权 CpG 分数，读数 < 10 记为未观测（掩码，不当 0）。

  • tf_promoterChIP ∩ ATAC ∩ 启动子三重重叠 → 因子到靶基因
  • tf_distal因子结合的 ATAC 峰落在环的对侧锚点，另一侧是靶基因启动子
  • promoter_contact两个启动子落在同一条环的两端（对称）
  • shared_element两个基因经环连到同一个远端 ATAC 峰（对称）

模型 A 把这些关系收成边；模型 B 不连边，而是给每个基因保留最多 24 个顺式元件 token （优先：启动子重叠 → 环连 → TSS ±50 kb 内最近）。两边的对照分别是：保持度数的双边交换，以及基因间重排 token 集合。

06 / 接口

零初始化门控：先验只能赢，不能一上来就毁骨架

扰动 token ← 标签嵌入 + Wp · z敲除基因   |   基因 g 的读出 ← q(h) · k(zg) / √d

Wp、读出相关的线性层，以及 Epi-GRN 的边支持项，全部从零开始。 所以第 0 步时两个模型与无先验骨架输出相同；只有当先验真能降低能量距离损失时，这些路径才会长起来。

07 / 对照

打乱结构，而不是丢掉特征

  • Epi-GRN换边

    每类关系做保持度数的双边交换；节点特征不动。真实边被保留的比例写在先验摘要里。

  • Epi-Direct换集合

    整套 token 按基因置换重挂；单个 token 内部的特征不变。

  • 骨架

    同一套 Transformer，完全关掉先验路径。

  • STATE 基线

    官方 state_sm，以及 perturb_mean / context_mean，同一 TOML、同一 cell-eval 协议。

怎么读这些数

在表观匹配的 K562 留出上，Epi-GRN / Epi-Direct 相对 STATE 在表达、区分和多数差异表达指标上更好； 但 打乱先验 常常与真实先验接近甚至略好——说明在本预算、本因子覆盖下，先验的几何未必稳定贡献， 骨架本身已经很强。context_mean 在若干表达指标上仍是强基线。

在 RPE1 留出上，先验来自 K562，属于跨细胞系迁移。Epi-Direct 的 pearson_delta 与部分 DE 重叠更好， 但 STATE 在部分召回类指标上仍有优势。单种子、20k 步、~18M 参数对 ~36M 可训练参数的 STATE-sm，不能外推到论文规模训练。

09 / 边界

这页能说明什么，不能说明什么

能说明：同一套公开表观证据可以接到 STATE 风格的集合到集合模型上；接口与评分可以和官方 CLI 对齐； 在该设定下可以逐指标比较。

不能说明：表观先验在任意预算下都优于无先验；K562 表观能无条件迁移到任意细胞系； 25 个源因子覆盖了相关调控；单次随机种子代表方差。仓库里的 results/ 只含汇总表，不含逐细胞矩阵或权重。
